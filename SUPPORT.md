## What to include when asking for help

- Node.js and npm version (`node --version`, `npm --version`)
- Operating system
- Package or lab path (e.g. `@embedded32/j1939`, `labs/lab-02-...`)
- Commands run and full error output
- Whether you ran `npm run build` from repository root

## Response expectations

This is a volunteer-maintained open-source project. Maintainers aim to respond to issues within several business days; there is no SLA.

## Not supported through this repository

- Live vehicle tuning or warranty repairs
- Commercial integration contracts
- Immigration or personal documentation requests
